    Enterprise & products

    ⓘ GitHub behavior and possible impact

    GitHub says added seats are billed pro rata and their included credits may also be prorated. Added licenses increase the pool immediately; removals reduce it at the next cycle.

    AI credit paid usage is enabled by default at enterprise level. Disabling it prevents overage spend but blocks AI-credit-consuming features after the eligible included pool is exhausted. Selecting products limits paid usage to those products and organizations cannot change it.

    Cost centers

    Caps included usage at the total AI credits that come with the Copilot licenses attributed to this cost center.
    ⓘ Cost-center attribution, pools, and exclusion impact

    For Copilot AI credits, user and enterprise-team cost-center assignments are the clearest model for included usage controls. Organization fallback is retained for allocation scenarios.

    Included usage controls for cost centers cap included credits funded by the cost center's attributed licenses. Excluded cost centers affect paid-overage budget roll-up, not included-pool capacity.

    Users

    ⓘ Seat removal behavior and billing impact

    Removing a seat does not produce a refund. Unassigned users keep access through the current cycle; revoked users lose access immediately. Billing stops at cycle end in both cases.

    GitHub Docs: Copilot license changes

    POLICIES

    Budgets and alerts

    User-level budget (ULB)Counts each user's total AI credits from both included pool and paid usage. Individual overrides cost-center user-level budget, which overrides universal. Always stops usage.
    Metered spending budgetCounts only paid overage after included credits are exhausted. Enterprise, organization and cost-center budgets can receive budget threshold alerts or stop usage when the budget limit is reached.
    ⓘ How GitHub evaluates budgets and alerts

    User-level budgets always stop usage and apply across included and paid phases. Individual overrides cost-center ULB, which overrides universal ULB.

    Metered budgets apply after the shared pool is exhausted. Without “Stop usage,” exceeding the amount sends alerts but does not prevent more spend. New budgets count usage only from their creation date.

    GitHub's standard alert thresholds are 75%, 90%, and 100%; user-level alert delivery is not consistently available. For Copilot, a $0 budget blocks applicable usage immediately.
